# HTML + CSS 標準入門 改訂2版｜授業用コード

Webクリエイター養成クラスの授業で使用する、HTML・CSSの学習用コードを共有するリポジトリです。

## 教材

- 書籍：『初心者からちゃんとしたプロになる HTML+CSS標準入門 改訂2版』
- 出版社・書籍情報：[MDN公式ページ](https://books.mdn.co.jp/books/3224303003/)

書籍に沿って学習する際の補助教材として、授業で扱うコードや練習用ファイルを掲載しています。書籍本文の代わりとなるものではありません。

## フォルダ構成

```text
.
├── L3_challenge/       # レッスン3のチャレンジ課題
│   ├── img/
│   └── index.html
├── lesson3/            # レッスン3のHTML・CSSと画像素材
│   ├── css/
│   ├── img/
│   └── index.html
└── lesson4/
    └── 01/             # レッスン4の練習ファイル
        └── index.html
```

授業の進行に合わせて、ファイルやフォルダが追加・更新されることがあります。

## ファイルの見方

1. このリポジトリをGitHubからダウンロードするか、Gitでクローンします。
2. プロジェクトフォルダをVisual Studio Codeなどのエディターで開きます。
3. 確認したい課題フォルダの `index.html` をブラウザーで開きます。
4. HTMLとCSSを編集して、表示の変化を確かめます。

ビルドやパッケージのインストールは不要です。CSSや画像を正しく読み込むため、HTMLファイルだけを別の場所へ移動せず、フォルダ構成を保ってください。

## 学習の進め方

- まず授業で説明されたファイルを読み、HTMLの構造とCSSの指定を確認します。
- コメントアウトされているコードは、授業の進行に応じて有効にして試します。
- 課題では、完成例を写すだけでなく、値や要素を変更して表示の違いを確認します。
- 不明点や課題の提出方法は、授業内の案内に従ってください。

## 注意事項

このリポジトリは授業用のコード共有を目的としています。画像などの素材やコードを、授業の範囲を超えて再配布・公開する場合は、それぞれの権利や利用条件を確認してください。
